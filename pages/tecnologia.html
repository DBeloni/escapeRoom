DECISÕES TÉCNICAS

Simples de executar.
Fácil de manter.

Objetos com estado

O projeto trabalha com objetos para representar jogador, cenas e configurações. A mesma lógica pode crescer para cada enigma: estado atual, dependências e métodos de interação.

JavaScript sem framework

Nenhum React, Vue, jQuery ou biblioteca de manipulação de DOM é necessário para a proposta. O site institucional também utiliza JavaScript puro.

Tecnologia

A proposta técnica exige HTML5, CSS3 e JavaScript Vanilla. Esta página transforma a arquitetura do repositório em uma explicação visual para quem estiver corrigindo o projeto.

HT

HTML5

Usado para a estrutura semântica das páginas, formulários, tabelas, imagens e mídia.

CS

CSS3

Usado para layout, responsividade, estados de hover, contraste e ambientação visual.

JS

JavaScript

Controla o estado, movimentação, cenas, timer, inventário, interação e futuros puzzles.

Boas práticas

Objetos com estado

O projeto já trabalha com objetos para representar jogador, cenas e configurações. A mesma lógica pode crescer para cada enigma: estado atual, dependências e métodos de interação.

Sem frameworks

Vanilla JS puro

Nenhum React, Vue, jQuery ou biblioteca de manipulação de DOM é necessário para cumprir a proposta.
